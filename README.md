# 소상공식 운영 대시보드

`index.html`을 더블클릭하면 브라우저에서 열립니다. 숫자는 파일 맨 위 `const DATA = {...}` 하나만 고치면 화면 전체가 바뀝니다.

1. `meta` — 마감일·총예산·건당한도·기준일을 고치면 상단 D-day·집행률·한도 경고가 바뀝니다 (`기준일: ""` 이면 오늘 날짜).
2. `team`·`tasks` — 담당자 열과 일정 막대·업무 카드가 바뀝니다. 마감이 지났는데 `상태`가 "완료"가 아니면 자동으로 지연 경고가 뜹니다.
3. `budget`·`expenses` — 예산 막대와 집행 표, 한도 초과·증빙 미확보·분할 결제 의심 경고가 바뀝니다. 두 곳의 `항목` 이름을 똑같이 적어야 합쳐집니다.
4. `mentoring`·`deliverables` — `확정일`을 채우면 「일정 미확정」 경고가 사라지고 일정 그림의 점선이 실선이 됩니다. 산출물 `상태: "완료"` 비율이 상단 완료율입니다.
5. `partners`는 파트너사 칸(골목사무국 B2G)입니다. `pilot`·`feedback` — 파일럿 단계 칸에 날짜를 적으면 ✓가 붙고 완료 건수가 올라갑니다. 지금 들어 있는 팀원 이름·일정·집행 내역은 예시이니 실제 값으로 바꾸고 `meta.샘플데이터`를 `false`로 두세요.
